# Heart Disease Prediction using Machine Learning

A Machine Learning project that predicts the risk of heart disease using a KNN (K-Nearest Neighbors) model.

## 🚀 Live Demo

**[Click Here to Open Heart Disease Prediction App](https://heart-disease-prediction-rhonwq3mk7doxhhj62gvb2.streamlit.app/)**

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- Scikit-learn
- KNN Algorithm
- Joblib

## ✨ Features

- Patient health information input
- Heart disease risk prediction
- Risk probability display
- Interactive Streamlit interface

## 📂 Project Files

- `app.py` – Streamlit application
- `KNN_heart.pkl` – Trained KNN model
- `scaler.pkl` – Feature scaling
- `columns.pkl` – Expected model input columns
- `requirements.txt` – Required libraries
